Fashion Portfolio - Responsive Webpage
A sleek, responsive fashion portfolio webpage built with HTML and CSS, featuring a dynamic layout, video integration, and mobile-friendly design.

📌 Overview
This project is my first hands-on experience with HTML & CSS, focusing on creating a fully responsive webpage with:

A structured grid layout

Smooth media queries for mobile adaptability

Interactive elements (video background, animated button)

Clean typography and visual hierarchy

🛠️ Features
✔ Responsive Grid Layout – Uses CSS Grid for desktop (3-column) and switches to a stacked design on mobile.
✔ Mobile-First Media Queries – Optimized for all screen sizes with adjusted fonts, spacing, and hidden/revealed elements.
✔ Video Background – Looping muted video for visual appeal.
✔ Animated Button – Floating circular arrow button with hover effects (positioned absolutely).
✔ Dynamic Typography – Responsive font scaling (vw units) for better readability.

📱 Responsive Behavior
Breakpoint	Layout Changes
Desktop	3-column grid, large typography, visible menu
Mobile (<600px)	Stacked layout, hidden menu (replaced by hamburger icon), adjusted font sizes
📝 Key Learnings
CSS Grid for complex layouts

Media queries for responsive design

Relative units (vw, %) for scalable typography

Positioning (absolute/fixed) for interactive elements
